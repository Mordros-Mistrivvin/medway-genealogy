# Medway Genealogy Research

Evidence-led research website for the Medway / Meadway family history project, with particular attention to Hamworthy, Poole, Lytchett Minster and Purbeck.

## Local development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Current research pages

- `/research/mary-galley/` — evidence for identifying Mary Galley, wife of Matthew Medway, with the Lytchett Minster baptism of 1760, including the 1749 Gally lease evidence (`D-DAS/4434A/B`) and related archival leads.

The site distinguishes proved facts, strong inferences and open hypotheses, and prioritises original records over derivative indexes and user-created family-tree links.
